Arabic letter pronunciation check

Manual test page for a physical desktop. It is not part of the website's navigation and not run by the automated tests.

Passing automated tests does not prove the voice pronounces these names correctly. Only listening does. For each letter, press Play (site), compare what you hear with the expected name, and mark it. Nothing on this page marks a letter "correct" automatically.
